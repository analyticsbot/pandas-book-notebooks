## Getting Started

```bash
# Clone this repo
git clone https://github.com/analyticsbot/pandas-book-notebooks.git
cd pandas-book-notebooks/notebooks

# Install dependencies
pip install pandas numpy matplotlib seaborn jupyter

# Launch Jupyter
jupyter notebook
```

## Requirements

- Python 3.9+
- pandas 2.0+
- numpy
- matplotlib
- seaborn
- jupyter
